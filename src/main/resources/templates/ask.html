How this works

This page is a Retrieval-Augmented Generation (RAG) endpoint. Your question is first embedded into the same 512-dimensional space as every published blog post, then ranked by cosine similarity (via MySQL 9 VECTOR_TO_STRING()). The top-5 posts become grounding context for Claude, which is instructed to answer using only those posts and to cite them with bracketed numbers like [1]. If the posts don't contain the answer, Claude is told to say so rather than invent facts.
